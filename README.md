# 衣橱 · 电子衣橱

把衣柜搬进手机：随手拍的衣服照片，由 AI 变成统一风格的商品图（浅灰底、正面、居中）；在你自己的形象上换装、转身看背面，记录每天穿了什么，统计每件衣服穿了几次、每次多少钱。

- **本地优先**：衣服、照片、穿搭、身材数据都只存在你的手机上，没有账号、没有服务器。
- **自带 Key**：AI 功能使用你自己的 OpenAI API Key，费用由 OpenAI 按用量直接收取。
- 目前提供安卓版（Android 7.0 及以上，arm64 手机）。

## 安装

1. 下载 `e-wardrobe-x.y.z.apk`，在手机上打开安装（第一次需要允许“安装未知应用”）。
2. 打开 App，按「今天」页的引导：填写 API Key → 录入衣服 → 建立形象。第一次发送照片前会询问你是否同意照片发送给 OpenAI。

**从 0.3.x 升级到 0.4.0**：0.4.0 起改用正式签名，Android 不允许直接覆盖旧版，需要：
旧版里「我的 → 完整备份（含照片）」→ 卸载旧版 → 安装 0.4.0 → 「我的 → 从备份恢复」。之后的版本都可以直接覆盖安装。

## 获取 OpenAI API Key

1. 打开 <https://platform.openai.com> 注册并登录。
2. 在 Billing 里充值（最低 $5，可以用很久）。
3. 在 <https://platform.openai.com/api-keys> 点 **Create new secret key**，复制以 `sk-` 开头的 Key。
4. 在 App 的「我的 → 我的 API Key」粘贴，点「验证并保存」。

Key 加密保存在手机系统的钥匙串里，只用于直接请求 OpenAI。

## 大概的费用（标准画质）

| 操作 | 每次约 |
|---|---|
| 录入一件衣服（识别属性 + 2 张候选商品图 + 保真检查） | $0.01–0.02 |
| 建立个人形象（正面 + 背面） | $0.05 |
| 生成一套穿搭的上身效果（每个视角） | $0.03 |
| 镜子照片识别 | < $0.01 |
| 真人大片 | $0.03 |

「我的」页面可以看到本月花费，并设置每月上限（默认 $5），到达上限后 AI 任务会自动暂停。

## 主要功能

- **录入**：拍衣服 / 拍吊牌 / 相册批量导入；AI 自动填名称、品类、颜色、季节，从吊牌读品牌、尺码、材质；每件生成 2 个候选，附带保真检查（颜色、细节、版型、面料是否和原图一致），也可以只存原图。
- **衣橱**：按品类分格，显示穿着次数、常穿排名；单品详情有每次成本、上次穿着、合身笔记。
- **试衣间**：免费的快速搭配预览；一键生成 AI 上身效果（正面 / 背面），按组合缓存。
- **穿搭**：保存搭配、按场合筛选；穿着日历，可以补记某天穿了什么。
- **今天**：按“多久没穿”推荐穿搭；拍镜子照片自动识别今天穿的衣服并记一次穿着。
- **数据**：Excel 导出 / 导入；**完整备份（含照片）/ 从备份恢复**，换手机时用；永久删除全部数据。

## 开发

代码在 `app/`（Expo SDK 58 / React Native 0.88 / expo-router / expo-sqlite）。

```bash
cd app
npm ci
npx jest            # 单元测试
npx tsc --noEmit    # 类型检查
npx expo lint
scripts/build-apk.sh   # 在 Linux 上构建 release APK
```

设计文档见 `docs/superpowers/specs/`，UI 原型在 `docs/prototype/`，开发交接说明见 `HANDOFF.md`。
