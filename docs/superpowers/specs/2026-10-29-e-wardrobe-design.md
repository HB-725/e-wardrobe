## 1. 产品是什么

一个手机上的电子衣橱。核心卖点是：**不管衣服怎么拍，进衣橱后都变成统一风格的商品图**（浅灰底、正面、居中、柔光，类似优衣库官网），然后可以把这些衣服**穿在用户自己的形象上**，像 QQ秀一样快速换装、转身查看，最后生成写实的上身大片。

### 优先级（用户确认）

1. 衣物管理（核心）
2. 穿搭制作与管理
3. AI 上身效果（个人形象、换装、旋转、真人大片）
4. 每日穿搭（天气、场合）——以后
5. 购物决策——以后

### 用户与规模

- 先给自己用（安卓），再给少量朋友试用（多数是 iPhone）。
- 不是商业产品，暂不上架应用商店。iOS 通过 TestFlight 分发，安卓直接发 APK。
- AI 费用由每个用户**用自己的 API Key** 承担（BYOK）。

### 非目标

- 不做尺码推荐或合身判断。上身图只用来看搭配效果。
- 不做真 3D 服装模型。"转身"只有正面和背面两个视角（AI 生成）。
- 不做社交、分享广场、电商导购。

### 页面清单

底部导航：**今天 / 衣橱 / 试衣间 / 穿搭 / 我的**（录入入口在衣橱右上角「添加」和今天页）

| 页面 | 关键内容 |
|---|---|
| 衣橱 | 文件夹式分类标签；4 列方格，每格是一件单品，右下角显示穿着次数；末尾补虚线空格作为"录入"入口；底部选中卡（名称、穿着次数、常穿排名、去试穿）。右上角显示总件数（**没有容量上限**，原型里的"/20 格"只是游戏感装饰，实现时改为"共 N 件"）|
| 试衣间 | 左边是人物形象 + 角度圆点 + 左右转身；右边是竖排品类栏 + 衣服栏，点一下穿上、再点一下脱下；左下角是"保存穿搭""生成真人大片" |
| 单品详情 | 标准图 / 原图切换；穿着次数、每次成本、上次穿着；属性列表（AI / 吊牌来源标记，空字段显示"点击填写"）；合身笔记；包含这件单品的穿搭 |
| 穿搭 | 本周穿搭日历；"拍镜子照记录今天"入口；按场合筛选；穿搭卡片 |
| 我的 | 个人形象；身材数据（只显示"已填写"）；AI 本月花费明细和上限；API Key；偏好；Excel 导出 / 导入；隐私与永久删除 |
| 录入：拍照 | 拍衣服 / 拍吊牌 / 相册批量 三种模式；取景框；实时提示 |
| 录入：确认 | 原图 vs 标准图并排；2–3 个候选方案；保真检查清单；可编辑字段（AI / 吊牌标记，选填字段留空）；"只存原图"或"保存，下一件" |
| 镜子照片校准 | 识别框；识别出的单品（可勾选或取消）；说明将如何修正上身效果；记录今天，穿着次数 +1 |
| 建立个人形象 | 3 步：3 张全身照 → 身高体重体型 → 生成正面 + 背面并确认 |
| 真人大片 | 场景选择；费用提示；保存到相册、分享、再生成（360° 视频暂不做）|

## 3. 技术架构（本地优先，已实施）

```
┌─────────────────────────────────────────────┐
│ 手机 App · Expo SDK 58（React Native 0.88）     │
│ · expo-router：src/app 下每个文件是一个页面       │
│ · expo-sqlite：全部数据（src/db 仓储层）           │
│ · expo-file-system：照片和生成图（文档目录 images/）│
│ · expo-secure-store：用户自己的 OpenAI Key        │
│ · JobRunner：SQLite 持久化的 AI 任务队列（并发 2）   │
└──────────────┬──────────────────────────────┘
               │ HTTPS（JSON，图片用 data URL）
        ┌──────▼──────┐
        │ OpenAI API   │  images/edits + chat/completions（视觉）
        └─────────────┘
```

- **没有后端**：数据、照片只存在手机上；只有在生成时把需要的图片发给 OpenAI。
- **BYOK**：用户在「我的 → API Key」粘贴自己的 Key，保存前调用 `/v1/models` 验证。
- **模型**：启动时通过 `/v1/models` 探测，按「最便宜优先」选择：图像 `gpt-image-1-mini`，视觉 `gpt-5.4-nano`（`reasoning_effort: none`）。列表里存在但已下线的模型（实测 `gpt-4.1-nano`）会在第一次报错时被拉黑并自动换下一个。
- **网页预览**：`expo export --platform web` 时，数据库换成 sql.js（`db.web.ts`），图片用 data URL，`?demo=1` 载入演示数据，用于 Playwright 截图验证 UI。
- **安卓包**：`expo prebuild` + `gradlew assembleRelease`（见 HANDOFF.md 的构建说明）。

## 4. 数据模型（SQLite，src/db/schema.ts）

| 表 | 说明 |
|---|---|
| `items` | 单品：名称、品类 slot、细类、颜色名/色值、季节、品牌、尺码、材质、价格（分）、购买日期/渠道、存放位置、合身笔记、状态（processing / review / active / failed / archived）、原图、标准图、吊牌图、候选图 `candidates`、保真检查 `checks`、字段来源 `field_sources`（ai / tag / user）|
| `outfits` + `outfit_items` | 穿搭（名称、场合）及其单品 |
| `wear_logs` + `wear_log_items` | 每天一条穿着记录（来源 manual / outfit / mirror，可带镜子照片）|
| `tryon_cache` | 上身效果图缓存，键 = 单品组合（排序后拼接）+ 视角，绑定形象版本 |
| `avatar` | 单行：正面/背面形象图、3 张原始全身照、身高体重体型、状态 |
| `jobs` | AI 任务队列：类型、引用、状态、尝试次数、退避时间、错误 |
| `usage` | 每次 AI 调用的估算费用（按模型单价 × 返回的 token 用量）|
| `settings` | 键值：AI 设置（上限、画质、候选数）、模型选择、暂停原因、偏好 |

派生统计（穿着次数、上次穿着、每次成本、闲置天数、常穿排名、本月花费）都在 `src/domain/stats.ts` 里实时计算。

## 5. AI 流程（src/ai）

| 能力 | 实现 | 实测（2026-10-29，gpt-image-1-mini + gpt-5.4-nano）|
|---|---|---|
| 统一商品图 | 视觉模型自动填属性（JSON Schema 严格输出，看不清填 null）→ images/edits 生成 2 个候选（"改拍摄不改衣服"）→ 视觉模型逐项保真检查 → 用户在确认页挑选 / 重新生成 / 只存原图 | 每件约 $0.014，约 20 秒 |
| 个人形象 | 3 张全身照 + 身高体重体型 → 正面（统一浅灰 T 恤短裤、赤脚、#F1F1F2 背景）→ 以正面 + 背面照生成背面 | 约 $0.045 |
| 快速换装 | 不调用 AI：形象图 + 商品图按身体部位贴在旁边，即时、免费 | — |
| 上身效果 | 形象（正/背）+ 各件商品图 → images/edits，按组合 + 视角缓存 | 每个视角约 $0.03 |
| 镜子照片 | 照片 + 衣橱单品缩略图（最多 40 件）→ 视觉模型返回编号、置信度、合身笔记；用户勾选后记一次穿着 | 约 $0.002 |
| 真人大片 | 形象 + 商品图 + 场景提示词 | 约 $0.03 |

错误处理：`AiError` 分类为 no_key / auth / quota / cap（需要用户处理 → 整个队列暂停并在今天页提示）、rate / network / server / model / bad_response（可重试，15s / 60s / 240s 退避，最多 3 次）、rejected（不重试，单品标记失败，可手动重试或只存原图）。App 被杀时正在运行的任务下次启动重新排队。

## 6. 隐私与安全

- 照片、身材数据、穿着记录全部在手机本地；卸载 App 即删除。
- API Key 存在系统钥匙串（expo-secure-store），不进 SQLite、不进 Excel 导出。
- 「永久删除我的全部数据」：清空数据库、删除图片目录、删除 Key。
- 身材数据在界面上只显示「已填写」。

## 7. 测试与验证

- Jest：领域逻辑、仓储层（sql.js 内存库）、AI 客户端（假 fetch）、任务队列（假客户端：暂停/恢复、退避重试、模型切换、上限、并发竞态）、业务动作、Excel 往返。
- `src/ai/__tests__/real.test.ts`：设置 `REAL_AI_DIR` 后用真实 Key 跑完整流程（约 $0.20）。
- 网页导出 + Playwright 截图核对每个页面；APK 由用户真机安装验证（构建机没有 KVM，跑不了模拟器）。
