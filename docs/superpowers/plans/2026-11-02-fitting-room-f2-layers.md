# 试衣间 F2 + 叠穿 实现计划

**目标：** 按设计画布定下的样子重做试衣间：全屏人物 + 底部抽屉（精简版 B），抽屉最前面是「已穿」，上身可以多层叠穿，能调里外顺序和穿法，AI 试穿按层和穿法生成。

**设计来源：** https://claude.ai/artifact/3zpeTSFattB9rStC2iq7aq
- 「F2 整套」：各状态（空、生成确认、生成中、背面、拖动、空分类、保存、没有形象、AI 暂停）。
- 「叠穿」「不重复显示」「做法 B」「精简版」：最终选的是精简版 + 做法 B 的「已穿」按钮。

## 定下来的规则

- 人物区只放人（生成后是上身效果），旁边不贴衣服小卡；标题旁不显示件数（「已穿」按钮上有数字）。
- 右侧圆形按钮：转身、生成 / 重新生成上身效果（先确认价格）、保存穿搭、生成大片。抽屉展开时淡出。
- 抽屉收起：一排「已穿 | 外套 上衣 下装 鞋 包 配饰」+ 一排衣服；没有细类那一排。上拉展开成 3 列网格，细类作为小标题分组。拖动或点把手开合，点人物区收起。
- 「已穿」：黑框方角按钮 + 人形图标 + 数字，后面竖线隔开分类。收起时一排，上身从外到里带层号，竖线后是其他，每件 × 脱下。展开后是穿着顺序：拖动换里外，选穿法（敞开 / 扣好，塞进 / 放外面），× 脱下。
- 叠穿：外套和上衣合称「上身」，最多 5 层。在外套或上衣里点一件：叠到最外面；如果同一类已经穿了一件，底部提示「X 叠在 Y 外面，是第 N 层」+「改成换掉 Y」。下装、鞋、包、配饰点了直接换。
- 其他分类里穿着的衣服：黑框 + 层号（上身）或勾（其他）；分类胶囊上小黑点表示这一类有穿。
- 还没穿衣服：抽屉上方提示「从下面挑衣服，点一下就穿上」。穿了才有「今天穿这套」。
- 空分类：「录入」虚线格 +「还没有X」。
- 没有形象：人物处放剪影 + 引导卡片（开始建立形象 / 先不建，直接搭配），抽屉照样能用。
- 生成中：左上角「正在生成上身效果」+ 人物上一道浅光扫过；AI 暂停：「AI 已暂停 · 去处理」。
- 从衣橱或单品详情「去试穿」：换掉同一类最外面那件（不叠）。从穿搭「在试衣间打开」：按保存的顺序和穿法，默认打开「已穿」。

## 数据

- `Look { ids, styling }`（`src/domain/look.ts`）取代 `Selection`：`ids` 里上身按从里到外的顺序，其他一类一件；`styling[id] = { open?, tucked? }`。
- `lookKey`：上身每类最多一件、上衣在外套里面、没有穿法时，和以前的 `outfitKey` 一样，已有的上身效果缓存还能用；否则在后面加上顺序和穿法。
- 穿搭保存顺序和穿法：迁移 4 给 `outfit_items` 加 `position`、`styling`；`Outfit.styling`。同一组衣服但顺序或穿法不同，算不同的穿搭。
- 试穿任务 payload 带 `itemIds`（按顺序）和 `styling`；`orderedGarments` 上身保持给定顺序。

## AI

- `tryonPrompt` / `photoPrompt` 收到每件的 slot 和穿法；上身两层以上（或有穿法）时写明从里到外的层次和每层怎么穿。只有一件上衣 + 一件外套且没穿法时，用原来验证过的写法。
- `tryonBackPrompt` 写明层次顺序。
